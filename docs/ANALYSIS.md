# קשב — איך מנתחים מתאמן יום אחרי יום, ומגיעים למסקנה מקצועית

טיוטת חשיבה · 2026-09-10 · לא נבנה עדיין

המטרה: לא "עוד גרפים". לקחת את כל הנתונים של מתאמן, לצבור אותם לאורך זמן, להצליב
אותם, ובסוף לתת **מסקנה מקצועית על האדם** — מה קורה איתו, למה, ומה לעשות.

---

## 1. איזה נתונים אוספים (הכל, אוטומטי)

### אובייקטיבי — מהשעון (דרך ייצוא TrainingPeaks / גרמין)

| קבוצה | מדדים |
|---|---|
| **שינה** | סה״כ שעות · עמוק / קל / REM / ערות · ציון שינה · שעת שינה ושעת קימה (עקביות) · זמן הירדמות · חוסר מנוחה |
| **מערכת עצבים / התאוששות** | HRV לילי (RMSSD) · סטטוס HRV (מאוזן / לא מאוזן / נמוך) · דופק מנוחה · קצב נשימה בלילה · SpO2 לילי · Body Battery (טעינה / התרוקנות / שיא בוקר) |
| **סטרס** | ציון סטרס יומי (גרמין) · דקות סטרס גבוה · דקות מנוחה |
| **פעילות** | צעדים · דקות פעילות · Intensity Minutes · קלוריות · קומות · זמן ישיבה |
| **אימון** | עומס אימון יומי (acute) · עומס כרוני · ACWR · סטטוס אימון (פרודוקטיבי / שמירה / overreaching / detraining) · מגמת VO2max · Training Readiness (של גרמין) · Recovery Time · פירוט אימונים: סוג, משך, דופק ממוצע/מקס, התפלגות זונות, TSS/TRIMP, הספק/קצב |
| **גוף** | משקל בוקר · אחוז שומן (אם יש משקל חכם) · שלב מחזור (למתאמנות) |

### סובייקטיבי — צ׳ק-אין יומי (כבר בנוי, ניתן להתאמה)

איכות שינה · אנרגיה · מצב רוח · מוטיבציה · כאבי שרירים (+ מיקום) · עומס נפשי / לחץ בחיים ·
RPE של האימון אתמול · תסמיני מחלה · כאב / נִיגְל (0–10 + מיקום) · הידרציה · אלכוהול ·
"משהו שכדאי שאדע" · דבקות בתזונה · תסמיני מחזור

### תקופתי

- **צ׳ק-אין שבועי מעמיק**: מגמת מוטיבציה · אירועי חיים · נסיעות · שינה בסביבה חדשה · הרכב גוף
- **חודשי**: בדיקת יעדים · תחושת התקדמות · סיכום שיחה
- **בדיקות דם** (כבר בנוי): פריטין, המוגלובין, המטוקריט, ויטמין D, B12, פולאט, CK, טסטוסטרון, קורטיזול, TSH/T3, CRP, ברזל/רוויון טרנספרין, מגנזיום, גלוקוז/HbA1c, שומנים
- **מבחני ביצוע**: TT, מבחן FTP, קפיצה (CMJ), כוח אחיזה

## 2. איך מנתחים — 4 שכבות

### שכבה 1 — עיבוד יומי לכל מדד (אוטומטי, דטרמיניסטי, בלי AI)

לכל מדד, לכל יום:
- **בייסליין אישי** — ממוצע נע 28 / 60 יום + סטיית תקן (או ממוצע מְשׁוֹקלל אקספוננציאלית)
- **סטייה מהבייסליין** — z-score ו-% סטייה
- **ממוצע נע 7 ימים** מול הבייסליין (מחליק רעש)
- **קצב שינוי** — שיפוע 7–14 ימים
- **ימים מחוץ לטווח הנורמלי** — מונה רציף
- **מקדם שונות** — האם ה-HRV של המתאמן הזה בדרך כלל יציב או תנודתי? (משנה מה נחשב חריג)

### שכבה 2 — ציוני תחום (מורכבים, יומי)

- **ציון התאוששות** = f(סטיית HRV, סטיית RHR, ציון שינה, Body Battery, נשימה)
- **ציון עומס / מאמץ** = f(עומס אימון, ACWR, צעדים, דקות פעילות, סטרס יומי)
- **ציון מוכנוּת סובייקטיבי** = f(אנרגיה, כאב, מצב רוח, מוטיבציה, איכות שינה)
- **דגל קוהרנטיות** = |התאוששות אובייקטיבית − מוכנוּת סובייקטיבית| — פער גדול = לחקור

> ציון המוכנוּת הנוכחי (נוסחה אחת גסה) מוחלף בזה.

### שכבה 3 — זיהוי דפוסים (נע, "ההצלבה")

הכלל: **יום בודד = רעש. מה שחשוב זה מגמה + התכנסות של כמה אותות + הקשר.**

חוקים שנדלקים כשאותות מתכנסים לאורך חלון:

| דפוס | מתי נדלק | המסקנה |
|---|---|---|
| **Overreaching לא-פונקציונלי** | HRV מדוכא ≥5–7 ימים + RHR מוגבה + אנרגיה/מוטיבציה יורדות + עומס גבוה/עולה | "תוריד עומס — זו עייפות מצטברת, לא הסתגלות" |
| **מחלה מתקרבת** | קפיצת RHR + נשימה למעלה + HRV למטה + SpO2 יורד + "מרגיש לא משהו" — 24–48ש׳ לפני תסמינים | "אולי מחלה בדרך, החזק עצימות, עקוב" |
| **לחץ חיים דומיננטי** | סטרס יומי גבוה + שינה גרועה + לחץ סובייקטיבי גבוה, אבל עומס אימון תקין + HRV מושפע רק קלות | "הבעיה לא באימונים — דבר איתו, התאם ציפיות" |
| **זמינות אנרגטית נמוכה / RED-S** (טווח ארוך) | משקל יורד + HRV נמוך + שינה גרועה + ליבידו/מצב רוח נמוכים + (דם) פריטין/טסטוסטרון/T3 נמוכים + נפח אימון גבוה | "בדוק זמינות אנרגטית, הפנה לבדיקה" |
| **שיבוש צירקדיאני** | שונות שעת שינה/קימה עולה + ציון שינה יורד | "היגיינת שינה / לוח זמנים" |
| **התנתקות / דה-טריינינג** | עומס יורד + צעדים יורדים + מוטיבציה יורדת + צ׳ק-אינים חסרים | "המתאמן מתרחק, צריך לחבר מחדש" |
| **הסתגלות חיובית** | היה עומס גבוה, עכשיו HRV מתאושש מעל הבייסליין + אנרגיה סובייקטיבית עולה + RHR יורד | "סופר-קומפנסציה — חלון טוב לאימון מפתח או מבחן" |

### שכבה 4 — המסקנה המקצועית התקופתית (שבועי/חודשי, בעזרת AI)

כאן נכנס Claude. **לא זורקים לו מספרים גולמיים** — נותנים לו את הפלט של שכבות 1–3
(מגמות, סטיות, התכנסויות) + הסדרות הגולמיות + ההקשר:

- פרופיל המתאמן: ענף, יעד, גיל, מין, ותק אימון, היסטוריית פציעות, מה "נורמלי" עבורו
- בלוק האימון הנוכחי (מה נקבע ב-TrainingPeaks)
- מרוצים/אירועים אחרונים, נסיעות, מחלות
- היסטוריית בדיקות דם
- **יומן המאמן** + ה"משהו שכדאי שאדע" מהצ׳ק-אינים

הפלט — **סקירת מתאמן מובנית**:

1. **סטטוס במשפט**: מתמודד טוב / מנהל / בסיכון / דורש התערבות
2. **מה הנתונים מראים** — המגמות, ההתכנסויות, בשפה פשוטה
3. **ההסבר הסביר ביותר** — הסתגלות / עייפות / מחלה / חיים / תת-תדלוק (עם דיפרנציאל)
4. **מה עובד / מה נסחף**
5. **המלצות קונקרטיות** — עומס, התאוששות, שינה, תזונה, הפניה רפואית
6. **מה לעקוב בשבוע הבא** — המדדים והספים הספציפיים
7. **שאלות לשאול את המתאמן** בשיחה הבאה
8. **רמת ביטחון** + איזה מידע יעלה אותה

**המנגנון "יום אחרי יום אחרי יום":**
- כל יום: שכבות 1–3 רצות אוטומטית (זול, דטרמיניסטי). מפיקות את ציון המוכנוּת והדגלים. זה מוקד הבוקר.
- כל שבוע: סקירת AI לכל מתאמן (שכבה 4), רצה ב-cron, **מצטברת** — כל סקירה מקבלת את הקודמת כהקשר, ועוקבת אם דגלים נפתרו או החמירו.
- כל חודש: סקירה עמוקה יותר + "השווה למצב לפני 3 חודשים".

## 3. מה הופך מסקנה ל"מקצועית" (ולא גנרית)

- ספציפית **לבייסליין של המתאמן הזה**, לא לנורמות אוכלוסייה
- מפרידה אות מרעש לפי השונות של המתאמן עצמו
- נותנת דיפרנציאל ("כנראה עייפות, אבל שלול מחלה ע״י בדיקת X")
- מעשית (שינויי עומס/התאוששות ספציפיים, לא "תנוח יותר")
- מכירה את הקשר האימון (דגל אדום בבלוק העמסה מתוכנן ≠ דגל אדום בטייפר)
- עוקבת לאורך זמן (מפנה לשבועות קודמים)
- כנה לגבי אי-ודאות
- **המאמן מתקן אותה** ("היא בעצם בנסיעות") — והתיקון הופך להקשר לפעם הבאה

שתי רמות: סקירה שבועית זולה (Sonnet, ~$0.02) · סקירה חודשית עמוקה (Opus, יותר היסטוריה).

## 4. ייעול ה-workflow של המאמן

- **דייג׳סט בוקר במייל** (לא רק הדשבורד): "3 דורשים תשומת לב היום: נועה (חוב שינה 6 לילות), איתי (RHR +6, אולי מחלה), דניאל (2 צ׳ק-אינים חסרים). 7 ירוקים." מבט אחד בטלפון.
- **מיון חכם**: לא רק לפי ציון — גם לפי "שינוי מאתמול" ו"מוסבר מול לא-מוסבר". אדום מתוכנן פחות דחוף מאדום בלי סיבה.
- **Snooze / אישור**: המאמן מסמן "ראיתי, דיברתי איתו" וזה מפסיק לנדנד.
- **משימות אוטומטיות**: דגל יכול לייצר משימה ("להתקשר לנועה לגבי שינה").
- **תזכורת צ׳ק-אין בלחיצה** למי שלא מילא.
- **השוואת מתאמנים** / מתאמן מול ממוצע הקבוצה.

## 5. תצוגות ומודולים חדשים

- **ציר זמן של מתאמן** — הכל על ציר אחד: עמודות עומס אימון + קו HRV + שינה + דגלים + מרוצים + הערות מאמן + סמני דם. זו תצוגת ה"לונג׳ביטי".
- **מפת חום של הקבוצה** — שורות = מתאמנים, עמודות = 14 ימים אחרונים, צבע = מוכנוּת. רואים דפוסים קבוצתיים (כולם צנחו אחרי המחנה).
- **קורלציות אישיות** — "ה-HRV שלך צונח הכי הרבה כשאתה ישן פחות מ-7 שעות" / "הכאב שלך קופץ יומיים אחרי ריצות ארוכות".
- **עומס מול התאוששות** (scatter) — הם בזון הפרודוקטיבי או בזון הסכנה?
- **מודול פציעה/כאב** — מפת גוף, 0–10, "משפיע על אימון", מגמה — שנִיגְלים לא הופכים לפציעות בשקט.
- **מודול מחזור** למתאמנות — קריטי לתכנון עומס.
- **מודול תזונה** — מעבר לטקסט: משקל שבועי, "פגעת בחלבון/פחמימות/הידרציה" 1–5, הערכת זמינות אנרגטית.
- **תצוגה למתאמן** — המגמה שלו + הערת המאמן בחזרה (מעורבות).
- **פלייבוק** — חוקים של המאמן ("אם HRV למטה 3 ימים, יום קל") שהמערכת מיישמת ומציעה.
- **דוח מתאמן להורדה** (PDF) — למתאמן, לפיזיו, להורה (נוער).

## 6. סדר בנייה מוצע

**עכשיו (קטן, ערך גבוה):**
1. לקלוט את כל סט המדדים (צעדים, סטרס, נשימה, SpO2, דקות פעילות, שלבי שינה, Garmin Readiness, VO2max) — עוד עמודות ב-`daily_metrics`. לעשות עכשיו כדי שהיסטוריה תצטבר.
2. טופס הזנה ידנית + מייבא CSV מ-TrainingPeaks לכל זה.
3. **בייסליינים אישיים + ציוני תחום** (שכבות 1–2) — מחליף את נוסחת המוכנוּת הגסה.
4. **ציר זמן של מתאמן** — התמונה הלונגיטודינלית.

**הבא:**
5. **חוקי דפוסים** (שכבה 3) — כאן חיה ה"הצלבה".
6. **סקירת AI שבועית לכל מתאמן** (שכבה 4) — ה"מסקנה המקצועית", ב-cron, מצטברת.
7. **דייג׳סט בוקר במייל** למאמן.
8. **יומן מאמן** (ציר זמן של הערות לכל מתאמן) — מזין את הקשר ל-AI.

**אחר כך:**
9. מפת חום קבוצתית · קורלציות אישיות · מודול פציעה · מודול תזונה · מודול מחזור · תצוגה למתאמן.
