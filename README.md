# Athlete Platform

פלטפורמת ניטור מוכנוּת יומי למאמן. מושכת נתונים משעוני גרמין של המתאמנים (שינה, HRV,
דופק מנוחה, Body Battery) ומשלבת אותם עם צ׳ק-אין סובייקטיבי יומי, לדשבורד "מוקד בוקר"
שהמאמן סורק כל בוקר.

- הקשר מלא ומוסכמות: [`CLAUDE.md`](CLAUDE.md)
- תוכנית בנייה בשלבים: [`docs/PLAN.md`](docs/PLAN.md)
- פרוטוטייפ עיצובי: [`docs/prototype/`](docs/prototype/)

## הרצה מקומית

```bash
npm install
npm run dev
```

http://localhost:3000
